# Faros Spain

Mapa interactivo de los faros de España, sus señales luminosas y sus datos técnicos. Una pieza visual creada por **David Antizar** para explorar la costa a través de sus luces.

![Estado](https://img.shields.io/badge/status-publicable-3b82f6) ![Hecho por](https://img.shields.io/badge/hecho%20por-David%20Antizar-f97316) ![GitHub Pages](https://img.shields.io/badge/deploy-GitHub%20Pages-1e40af)

## Qué Es

Faros Spain convierte datos de señalización marítima en una experiencia cartográfica:

- Mapa oscuro con faros principales y secundarios.
- Marcadores animados que parpadean según la secuencia de cada luz.
- Panel lateral con periodo, alcance, altura, color y sectores.
- Reloj radial donde 360 grados equivalen a 60 segundos.
- Lectura poética y técnica del territorio costero.

## Enfoque Visual

El proyecto usa una dirección visual inspirada en **Ntizar Aurora Midnight**:

- Azul profundo para el fondo y la navegación.
- Naranja Antizar como acento de energía y señal.
- Superficies glass oscuras para mantener foco en el mapa.
- Contraste náutico para datos, luces y estados técnicos.

## Tecnología

- HTML, CSS y JavaScript sin build.
- Leaflet para el mapa.
- CARTO / OpenStreetMap como base cartográfica.
- GitHub Pages para publicación estática.
- Ntizar Aurora v5.1 como referencia visual de marca.

## Uso Local

Abre `index.html` directamente en el navegador o sirve la carpeta con cualquier servidor estático.

```bash
npx serve .
```

## Deploy

El repositorio incluye un workflow de GitHub Pages. Cada push a `main` publica el contenido de la raíz.

URL esperada:

```text
https://ntizar.github.io/farosspain/
```
